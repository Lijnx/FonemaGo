# Контент: отбор и ограничения демо

|---|---|---|---|
| Испанский | [β̞] | beber | Неполное смыкание губ во втором b |
| Испанский | [θ] | zapato | Зубной щелевой, вариант с distinción |
| Испанский | [ɲ] | niño | Палатальный носовой ñ |

| Итальянский | [ɔ] | otto | Открытая первая гласная, не финальная o |

Это **не список всех звуков, отсутствующих в русском**, и не полный курс. Включён
похожий на русский [r], поскольку его употребление и отличие от [ɾ] важны для
испанского. Отдельных упражнений на минимальные пары нет.

Испанский: все выбранные записи слов в соответствующем разделе английского
Wiktionary помечены Spain/Castilian Spanish. Поддерживается вариант Испании с
различением /s/ и /θ/, не все акценты Испании одновременно. Итальянский: выбраны
итальянские разделы и стандартные транскрипции; регион аудиозаписей не заявлен.
Это явно указано в карточках, стандартность самого звучания без прослушивания не гарантируется.

## Что проверено, а что нет

Выполнена проверка по текстовым источникам и метаданным:

- языковой раздел слова, написание и перевод;
- транскрипция, наличие и положение целевого звука;
- долгота итальянских согласных и различие открытых гласных;
- региональная пометка испанской записи;
- конкретный файл из Commons, авторство и применимая лицензия;
- скачивание закреплённых оригиналов, SHA-256, длительность и наличие аудиопотока;
- преобразование без обрезки и изменения скорости, комплектность MP3.

**Слуховое прослушивание и независимая экспертная рецензия не выполнены.**
Статус `reviewed_demo` означает именно отбор по источникам для демонстрации,
не сертифицированный эталон. Флаг `audio_listened: false` сохранён в evidence.
Техническая проверка FFprobe не подтверждает правильность произношения.

Отдельные IPA-аудио — общие артикуляционные образцы, часто со вспомогательными
гласными. Они не объявляются произношением носителя Испании/Италии и не обязаны
показывать долготу в конкретном слове. Подсказки предупреждают о важных различиях.

### Почему нет исходного примера dedo

Доступная в выбранном разделе запись `dedo` помечена Colombia. Она не подменена
испанским произношением Испании. Ссылка на dental approximant ведёт в статью,
где рядом есть разные записи [ð] и [ð̞]; первое аудио брать автоматически нельзя.
Пример можно добавить позже при нахождении подходящей записи слова и проверке пары.

Также не использован общий `Voiced_velar_approximant.ogg` как бесспорный образец
испанского [ɣ̞]: описание этого файла использует [ɰ]. Для демо выбран менее спорный набор.

## Источники и права

- `content/catalog.json`: ссылки на статьи/словари для каждой карточки и метаданные
  каждого аудио: автор, страница Commons, лицензия, SHA-256 и преобразования.
- `content/catalog-evidence.json`: постоянные ссылки на ревизии файлов Commons,
  выбранная лицензия, авторские исключения для старых шаблонов и статус прослушивания.
- Авторство аудио отображается в **каждой** отправке эталона, включая повтор при сравнении.
- Для [d͡ʒ] файл Octane опубликован как PD-self. Public Domain Mark в метаданных —
  ссылка на описание статуса, а не утверждение, что автор применил CC0.
- Для файлов с несколькими лицензиями выбрана указанная в каталоге CC BY-SA.
  Footer-лицензия сайта не используется как лицензия аудиофайла.
- Для [ɛ] выбран файл RoachPeter с явно указанным автором, а не запись с
  автоматически предполагаемым авторством.
- Подготовленные MP3 сопровождаются указанием преобразования и той же выбранной
  лицензией, что у оригинала. Не заявляется, что это собственные записи проекта.
- Русские подсказки написаны для этого демо. Каталог/текстовые адаптации доступны
  по CC BY-SA 4.0; независимые аудиофайлы сохраняют собственные лицензии.

Wikimedia не гарантирует правильность авторских сведений; для публичного продукта
нужна дополнительная проверка содержания и условий использования, не только парсер.

## Как добавить карточку

### 1. Собрать кандидатов

```bash
uv run fonemago collect-ipa Spanish
uv run fonemago collect-ipa Italian
uv run fonemago collect-word Spanish dedo
uv run fonemago collect-word Italian figlio
uv run fonemago collect-file 'Voiced_dental_approximant.ogg'
```

Результаты выводятся JSON в stdout и **не изменяют живую базу**. Для сохранения
используйте новый файл вне `content/catalog.json`, например `data/new-word.json`.
Не направляйте вывод в существующий утверждённый каталог.

Парсер поддерживает языковые секции MediaWiki/Parsoid и извлекает несколько IPA
и несколько записей. Он не угадывает нужный акцент, смысл или первое подходящее аудио.
В отсутствие данных выдаёт ошибку или пустой список, а не синтезирует недостающие записи.
API Wikimedia в этой среде отвечал 403, поэтому используется ограниченный разбор HTML.
Изменения в разметке могут потребовать обновления сборщика и тестовых фикстур.

### 2. Проверить вручную по источникам

1. Определить точный звук/аллофон и выбранный региональный вариант.
2. Выбрать слово, в котором именно в указанной позиции есть целевой звук.
3. Сопоставить транскрипцию с источником. `/…/` — фонемная, `[…]` — фонетическая;
   не менять скобки ради единообразного оформления. В испанском демо сохранены
   фонетические транскрипции, чтобы [β̞] был виден непосредственно в слове.
4. Проверить регион и при возможности прослушать аудио, не заменяя проверку
   прослушиванием синтезатора или совпадением имени файла.
5. Проверить описание именно отдельного образца: фрикатив/аппроксимант,
   боковой/небоковой, дополнительные гласные и т. п.
6. Проверить автора и файл-специфическую лицензию, сохранить ревизию страницы.
7. Подготовить короткую оригинальную русскую подсказку и корректный перевод.
8. Зафиксировать ограничения проверки; при сомнении оставить `draft`.

### 3. Добавить данные

Добавьте в `assets` новый стабильный ID (не переиспользуйте существующий), источник,
download URL с `upload.wikimedia.org`, SHA-256 оригинала, суффикс, автора, лицензию,
ссылку на неё и описание преобразования. Для карточки укажите существующий код языка,
два asset ID, слово, транскрипцию, перевод, IPA, подсказку, источники и `sort_order`.

Изначально используйте `review_status: "draft"`. Только после проверки меняйте
на `reviewed_demo`. Это локальная операция владельца, не кнопка для пользователей.
Разрешённые поля и ограничения задаёт `src/fonemago/content.py`; новые данные
проверяются теми же моделями. Публикуется один пример слова на карточку.

Только для воспроизведения **исходной подборки** существует:

```bash
uv run python scripts/build_demo_catalog.py --output data/recollected-demo.json
```

Скрипт не перезаписывает существующий output. Он использует заранее выбранные файлы
и индивидуально проверенные исключения автора/PD; это не автоматический фонетический
рецензент. Повторный результат обязательно сравните с утверждённым каталогом и
контрольными суммами; не публикуйте его автоматически.

### 4. Подготовить и опубликовать

Остановите бот, сохраните backup и предыдущий каталог. Затем:

```bash
uv run fonemago prepare
uv run fonemago validate
uv run fonemago import-content
```

Если что-то не прошло — исправляйте черновик, не отключайте проверки. После публикации
перезапустите бот и проверьте отображение и оба аудио. Увеличение числа карточек уже
поддерживается пагинацией, без изменения обработчиков.
