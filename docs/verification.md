# Проверка реализации MVP

Выполнено в среде разработки:

- `uv run pytest -q`: **53 теста**, успешно, Python 3.14.4.
- `uv run --isolated --python 3.12 pytest -q`: те же **53 теста**, успешно, Python 3.12.14.
- `uv run ruff check .`: успешно.
- Реальный сбор таблицы IPA Spanish: получены кандидаты со ссылками и примерами.
- Сбор стартового набора: 12 карточек, 22 уникальных исходных файла Commons.
- Оригиналы скачаны, закреплены SHA-256; MP3 подготовлены FFmpeg.
- Все 22 MP3 проверены FFprobe и полностью декодированы FFmpeg без ошибок;
  длительность положительна и меньше 30 секунд. Это техническая, не слуховая проверка.
- `fonemago validate`: успешно.
- `fonemago import-content`: в SQLite по шесть активных карточек es/it.
- Реальная SQLite скопирована backup API в отдельный временный каталог,
  копия открыта и проверена: оба каталога восстановлены.
- `scripts/run.sh` корректно запускает приложение и без токена выдаёт понятную ошибку.

Системный FFmpeg в этой среде отсутствует, sudo требует пароль. Для разовой подготовки
и проверки использованы FFmpeg/FFprobe из временного окружения `uv --with static-ffmpeg`.
Это **не зависимость проекта** и не замена инструкции установки системного FFmpeg.
Подготовленные файлы уже находятся в `data/audio/`; для обычного запуска FFmpeg не нужен.

Не выполнено и не заявляется выполненным:

- настоящий обмен сообщениями с Telegram (токен владельца ещё не настроен);
- визуальная проверка клиента Telegram и голосового с настоящего телефона;
- независимая фонетическая рецензия или прослушивание записей человеком;
- проверка systemd на конкретной установке владельца;
- тест реального выключения/включения хоста;
- нагрузочное тестирование и подтверждение SLA.

Для завершения приёмки настройте `.env`, запустите бот и пройдите
[чек-лист](run-linux.md#8-короткий-чек-лист-перед-демо). Токен в переписку не передавайте.
