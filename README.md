# FonemaGo

Telegram-бот для самостоятельной тренировки произношения испанского и итальянского.
В демо — по шесть звуков на язык: образец звука, слово с транскрипцией и переводом,
запись слова и короткая подсказка по произношению. Испанский — вариант Испании.

## Как заниматься

1. Откройте чат с ботом и отправьте `/start`.
2. Выберите **Español** или **Italiano**, затем звук.
3. Послушайте отдельный звук и пример слова.
4. Нажмите **«🎤 Повторить слово»** и запишите слово обычной кнопкой микрофона Telegram.
5. Бот пришлёт образец слова и вашу запись рядом. Переслушайте и сравните самостоятельно.

Голосовое — до **15 секунд и 1 МиБ**. Кнопка бота не включает микрофон автоматически.
Вернуться к выбору языка можно через `/language`, получить справку — `/help`.
`/cancel` отменяет ожидание записи; `/forget` удаляет ваш выбор из рабочей базы бота.

**ИИ-оценки и распознавания нет.** Записи не скачиваются на оборудование владельца,
но остаются в Telegram-чате. Материалы отобраны по открытым источникам для демо,
без независимой экспертной и слуховой проверки. Источники и лицензии доступны в боте.

Публичный адрес бота ещё не настроен. Чтобы запустить свой экземпляр:
[инструкция под Linux](docs/run-linux.md). Для разработки:
[документация](docs/development.md), [проверка контента](docs/content-review.md).
